# Kết quả Gemini

Anh Phụng lưu bảng Gemini xuất ra vào đây, chia theo đợt:

- `dot-<n>/<tinh-moi>__<tinh-cu>.md` — G1 + G3 (địa danh, món, quán, chỗ ở, lễ hội)
- `dot-<n>/dau-moi__dot-<n>.md` — G2 (đầu mối đi lại)

Tên tỉnh viết không dấu, nối bằng gạch ngang, ví dụ `gia-lai__binh-dinh.md`, `quang-tri__quang-binh.md`.
Muse đọc các file này để làm mảng M2 (xem `../muse.md`).
